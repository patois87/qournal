# Icons

The icon themes of Xournal++ (`ui/iconsColor-*` and `ui/iconsLucide-*` of its repository), licensed under the GNU
GPL v2 or later like Xournal++ itself. The Lucide themes are based on the [Lucide](https://lucide.dev) icons (ISC
License).

`color-light` only has the icons Xournal++ does not take from the icon theme of the desktop; for the others the
Lucide icons are used.

The icons Xournal++ takes from the icon theme of the desktop (`zoom-in`, `zoom-out`, `zoom-fit-best`,
`zoom-original`, `go-first`, `go-previous`, `go-next`, `go-last`, `edit-delete`, `edit-find`) are Lucide icons
(lucide-static 0.460.0: zoom-in, zoom-out, scan, scan-search, chevron-first, chevron-left, chevron-right,
chevron-last, trash-2, search), in the colours of the Lucide themes of Xournal++.
